Hướng dẫn Cron Job

Để hệ thống tự động tạo bài và kiểm tra Facebook, bạn cần thiết lập cron trên máy chủ:

# Tạo bài hàng ngày lúc 8h sáng
0 8 * * * cd /đường/dẫn/phongthuy_site && /đường/dẫn/venv/bin/python generate_daily.py >> /var/log/phongthuy_daily.log 2>&1

# Kiểm tra Facebook mỗi 6 giờ
0 */6 * * * cd /đường/dẫn/phongthuy_site && /đường/dẫn/venv/bin/python fb_monitor.py >> /var/log/phongthuy_fb.log 2>&1

Lưu ý: Website không tự chạy các tác vụ này nếu chưa cấu hình cron hoặc dịch vụ lập lịch trên máy chủ.
